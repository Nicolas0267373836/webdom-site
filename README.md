# WebDom

Landing page de WebDom — diseño y desarrollo de páginas web para negocios de San Pedro de Macorís, República Dominicana, con seguimiento de Google Business Profile incluido.

Sitio estático de una sola página (HTML/CSS/JS, sin build). Incluye un cotizador interactivo de planes y un formulario de contacto directo a WhatsApp.

## Desarrollo local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue

Este proyecto está pensado para desplegarse en [Vercel](https://vercel.com) como sitio estático — no requiere configuración de build.
